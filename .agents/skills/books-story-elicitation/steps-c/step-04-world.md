# Step 4: World-building & Setting

**Progress: Step 4 of 5** - Next: Compilation

## STEP GOAL:
Establish the setting, time period, and rules of the world.

## MANDATORY EXECUTION RULES:
- 🛑 NEVER generate content without user input.
- 💬 Ask exactly ONE set of questions based on this step's goal.
- ⏸️ Wait for the user to answer before moving to the next step.
- ✅ Keep the user's answers from previous steps in memory.

## Sequence of Instructions

### 1. Present the Questions
Ask the user the following in a conversational tone:
1. Câu chuyện diễn ra ở đâu và vào thời gian nào (bối cảnh)? 
2. Có quy tắc hay yếu tố đặc thù nào về thế giới này mà tôi cần biết không? (Ví dụ: hệ thống phép thuật, công nghệ tương lai, luật lệ xã hội ngầm...)
3. Bầu không khí chung của câu chuyện là gì? (Ví dụ: u ám, tươi sáng, hài hước, căng thẳng...)

### 2. Wait for User Input
Halt execution and wait for the user to answer. 

### 3. Handle Continuation
Once the user answers:
- Briefly acknowledge their answer.
- Then, output: "Tuyệt vời! Tôi đã thu thập đủ thông tin. Đang tiến hành biên soạn Story Bible..."
- Read fully and follow: `./step-05-compile.md`
